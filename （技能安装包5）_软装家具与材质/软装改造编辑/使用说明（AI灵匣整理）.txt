软装改造编辑——**给一张已有的室内设计图做外科手术式精准修改**：先分析参考图里的物件、风格与材质，再生成针对性的编辑提示词，**保留你不想动的元素，只修改指定部分**。

**典型玩法：** 改风格（变 Japandi）· 换家具（换成分体沙发）· 调色（更暖的灯光）· 加/删元素——基于参考图做这些，而不是凭空重画。

**自动预处理（强制先跑）：** 生成前探测项目预处理产物（深度图/边缘图/语义分析/分割图/蒙版）——缺深度或语义分析就**自动补跑房间预处理**（不问用户）；要改特定元素但没蒙版就自动跑目标元素蒙版。全流程静默执行，用户无感知。

## Step 1 场景盘点（穷尽式清单）

有语义分析就直接读取（给出准确的风格/材质/颜色/灯光），否则逐项人工盘点，**能看见的都必须列上**：

```
房间类型/尺寸 → 固定件（台面/柜/窗/嵌入）→ 家具逐件
风格：主风格 + 次要影响 + 时代/情绪
材质清单：[材质]：[用在哪]
配色：主色/次色/点缀
灯光：类型(自然/人工/混合) + 光源 + 情绪 + 方向
相机：角度(视平/俯/低/鸟瞰) + 镜头感 + 构图
```

> 缺一项 = 重渲染时这项会凭空消失。清单必须穷尽。

## Step 2 变更差异分析 & Step 3 生成编辑提示词

**差异分析（Diff）五类：**
- **KEEP 保留**：[元素]：[保留理由]
- **MODIFY 就地改**：[元素]：[现状] → [目标态]
- **ADD 新增**：[元素]：[描述/位置]
- **REMOVE 删除**：[元素]：[理由]
- **STYLE SHIFT 风格迁移**：从 [现风格] → 到 [目标风格]，列出关键词/材质/颜色的新旧对照

**两种编辑策略（按改动幅度与厂商能力选择）：**
- **全文重渲染提示词**：给无编辑 API 的厂商（如 Midjourney）——完整描述最终效果，保留不改的布局与构图，风格词汇从风格库取
- **局部重绘（Inpaint）提示词**：给支持编辑 API 的厂商（DALL-E edit / Stability inpainting）——只描述蒙版区域要放什么 + 周边保持一致的上下文

有深度图时提示词注明「保持深度图所示空间布局」、有蒙版注明「只改蒙版区域」——把控制图的多模态上下文喂给模型。

## 输出格式 & 防坑规则

**输出：** ① 场景分析 ② 编辑计划（Diff） ③ 各厂商提示词（全文重渲染 + 局部重绘，如支持） ④ 用到的风格关键词 ⑤ 建议（哪种策略/哪个厂商最合适 + 潜在问题，如「风格混合可能产生不协调家具」）。

**Tips：** 改风格保布局 → 强调空间描述与相机角；换单品 → inpaint 优先（一致性最好）；只调色/光 → 最小改动聚焦氛围段；加植物装饰 → 相对现有物件的具体位置。

**Gotchas：**
- 小改（换一件、调色）用 inpaint；风格大改/布局大动用全文重渲染更稳
- **相机角保持是生命线**：重渲染若改了机位，图就变成「另一间房」而不是「这间房改了」——永远显式写回原相机角与镜头感
- 想全换（风格+家具+颜色+灯光）那是**重设计**不是编辑——转「AI室内设计咨询」流程
- 参考图低清/强压缩会毁掉盘点质量，尽量要最好的原图

## 使用技巧

1. 只改小局部用局部重绘、大改风格用全文重渲染，别用反
2. 明确保留项：告诉它哪些绝对不能动，防误伤
3. 换风格前先查风格库词汇，词不准会出「杂交怪图」
