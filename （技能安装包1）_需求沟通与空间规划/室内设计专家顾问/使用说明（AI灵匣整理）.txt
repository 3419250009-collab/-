高预算：三层全上 + 智能控制

## 配色决策流

1. 先评估自然采光：朝北 → 用暖色调（避开冷灰）；朝南 → 可承受冷色调；朝东/朝西 → 分时段实测
2. 再按房间功能定优先级：睡眠/放松 → 低饱和暖色（明度值 6-8）；工作/专注 → 中饱和平衡色温（明度 5-7）；娱乐会客 → 可接受更高饱和（明度 4-9）
3. 最后按尺度需求：想显大 → 高明度（7-9）+ 冷色相；想显温馨 → 中明度（4-6）+ 暖色相

## 五大失败模式（先识别、再修正）

**① 跟风网红 · 不看户型硬套潮流**
症状：中古家具塞进维多利亚老宅；北向暗房刷成北欧全白。
修正：先分析真实条件——房间比例、采光质量、建筑风格、生活方式，再谈风格。

**② 灯光荒漠 · 只有一盏主灯**
症状：人脸阴影生硬、看书费劲、氛围无法调节。
修正：灯光分层——台灯做环境光、活动区加任务光、调光开关做弹性。

**③ 尺度失明 · 家具尺码不对**
症状：家具间距 <450mm、转角沙发占掉 50%+ 动线；面积够却转不开身。
修正：先画动线（主通道 900-1200mm），再用剩余空间定家具尺寸。

**④ 盲选涂料 · 不看实墙就定色**
症状：上墙后颜色完全变样、与灯光冲突、返工重刷花钱。
修正：在你家真实光照下贴 60×60cm 以上的大样，实测 48 小时以上再定。

**⑤ 全套搭配陷阱 · 全部来自同一系列**
症状：房间像展厅样板间，没有人味与视觉趣味。
修正：60-30-10 法则——60% 中性打底、30% 协调元素、10% 点缀色/风格单品。

## 实战示例

**示例 A · 25m² 小开间逆袭**：北向窗 + €3000 预算 + 年轻白领。
① 空间分析：北光 → 需要暖色倾向；单间 → 必须分区。按决策树走北欧风 + 策略性分区。
② 布局策略：动线画好（入户→厨房→睡眠区，保持 900mm 宽）；分区：睡眠（角落）、办公（窗边）、休闲（中央）、做饭（一字厨房）。
③ 配色、家具按决策流逐层落定——重点是把光引进来、把分区做明确。

**示例 B · 有娃家庭的过渡风改造**：
① 约束分析：层高低 → 不吊大灯；有幼儿 → 无锐角、无易碎品。按决策树选中型+家庭 → 过渡风 + 安全优先。
② 灯光挑战：原只有一盏中央灯造成阴影生硬 → 避开「灯光荒漠」，改三层布灯而非升级单灯。
③ 分层落地：环境光 = 3000K 可调光筒灯替换主灯；任务光 = 阅读椅旁落地灯（摇臂可调）；重点光 = 电视后灯带 + 边几台灯。
④ 安全整合：圆角茶几、电视上墙、插座加盖、幼儿动线上不放落地灯。
⑤ 取舍分析：与其买多件廉价家具，不如买一件高性能面料的耐造沙发。

## 交付前质量门（逐项自检）

- [ ] 动线验证：所有主通道 ≥900mm、次通道 ≥600mm，无死胡同家具布置
- [ ] 灯光分层：至少两层（环境+任务），且可独立控制
- [ ] 颜色实测：涂料/主布艺大样在真实光线下实测 ≥48 小时
- [ ] 尺度比例：茶几长度约为沙发的 40-50%，地毯延伸至家具前腿之下
- [ ] 视觉重量均衡：任何单一象限的视觉质量（深色/大家具）不超过 60%
- [ ] 功能分区明确：每项活动有专属空间与配套灯光/收纳
- [ ] 电路确认：灯具插座足够，无拖线板横穿走道
- [ ] 预算分配核对：家具 60% / 灯光 25% / 饰品画作 15%
- [ ] 风格一致：60-30-10 法则已用
- [ ] 客户签字：主要决策（颜色/布局/关键家具）实施前均已获客户确认
