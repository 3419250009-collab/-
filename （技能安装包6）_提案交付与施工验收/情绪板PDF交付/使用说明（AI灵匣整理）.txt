情绪板 PDF 交付——把项目文件夹里的一堆**产品剪报（Markdown）自动排版成专业 PDF**。输出 17×11 英寸横版：**封面页**（项目名/工作室/房间索引/自动生成徽标）+ **每房间一页情绪板** + **产品规格页**（每页 3 个产品卡）。

**视觉风格——编辑风极简：** 暖亚麻底（#EAE5DC）、Times-Italic 斜体房间标题、规格页深色全宽页眉条、橄榄绿字段标签——像高端设计杂志的排版质感。

## 两种布局模式

**① 横排模式（row，默认）** —— 适合**材料板/饰面板/织物样板块**：顶部「materials」Times-Italic 斜体标题，图片单行横排撑满页高。触发词：material board / finishes / fabrics / samples / swatches。

**② 网格模式（grid）** —— 适合**灵感板/家具板/灯具板/概念板**：顶部「inspiration」斜体标题；≤3 图 2 列、4+ 图 3 列自动排；可选在图片上方加**色板圆点行**（0.55 英寸彩色圆点）。触发词：inspiration board / mood board / furniture board / fixtures / concept board。

## 字段自动解析（每个产品剪报）

标题/副标题 · 厂商 · 材质（MATERIAL 行）· 饰面（FINISH 行）· 尺寸（SIZE/DIMS）· 价格（自动扫 $）· 应用（APPLICATION）· 可持续认证（FSC/GREENGUARD/CARB/LEED/FloorScore/Red List Free 自动识别）· 规格（SPECS）· 来源/SKU · 图片（优先本地嵌入、兜底 URL）——**解析全自动，剪报写对字段就出对卡**。

## 规格页结构 & 颜色定制

**产品规格页（每页 3 卡）：** 全宽深色页眉（项目名左、年份右）→ 3 个产品卡左起排：大图（卡高 57%，白底）→ 产品名（Times-Bold 12pt）→「厂商 · 系列」灰字 → 描述 → 细线 → 规格字段行（橄榄绿粗体标签 + 6pt 字段值）→ 页脚「作者 · 年份」。

**全程可定制（CLI 覆盖颜色）：**
```
--layout row|grid           情绪板布局（默认 row）
--palette "#hex,…"          网格模式色板圆点
--spec-fields "material,…"  只显示指定规格字段
--color-bg / --color-accent / --color-text
--color-dark / --color-rule / --color-caption   全色系覆盖
```

## 常见问题与交付建议

**环境要求：** 网格模式需 Playwright（一次性装 Chromium ~150MB）；图片来源被 403 会自动换 UA 重试。

**常见场景处理：** 情绪板图太多 → grid 网格模式优雅承载（10+ 项别用横排）；缺可持续信息 → 自动搜「厂商+认证」只采可验证项；无 Logo → 自动生成绿底白字首字母徽标；规格页最后不满 3 个 → 从左补、空格留白。

**对设计师的价值：** 选品完成 → 产品剪报进文件夹 → 一键出**客户可交付的排版级 PDF**（封面+情绪板+规格页三件套）。与「家具排期表生成」同源配套：情绪板 PDF 用于概念汇报展示，排期表 xlsx 用于施工落地。
