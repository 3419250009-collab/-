# AutoCAD自动化制图与出图
**一句话定位：**不是“教你怎么用 CAD”，而是让 AI 直接打开 AutoCAD 把图画出来、按国标图层出图、再自动复核。

━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

## 它能替你做什么

把“画图”这件事从手工操作变成一条可复用的自动化流水线——你说需求，AI 生成绘图计划，AutoCAD 真实打开并逐步落图，画完自动统计实体、导出预览、出复核报告。

**1. 直连 AutoCAD 真机绘图**
通过 Python COM/ActiveX 连接 `AutoCAD.Application`，可新建文档、建图层、画线/圆/弧/多段线/矩形/文字/块/标注，保存 DWG 并导出 DXF、PDF。默认“可见逐步绘图”模式——先把 AutoCAD 拉到前台，再一点点把图元画出来，你能亲眼看着它画。

**2. 住宅装饰制图标准（本包增强）**

| 图层 | 用途 | 图层 | 用途 |
|---|---|---|---|
| A-AXIS | 轴网 | C-CEIL | 天花造型 |
| S-WALL-LOAD | 承重墙 | C-LAMP | 灯具 |
| S-WALL-PART | 非承重隔墙 | E-SW / E-SO | 开关 / 插座 |
| S-WALL-NEW | 新建墙体 | P-WATER / P-DRAIN | 给水 / 排水管 |
| S-WALL-DEM | 拆除墙体（虚线） | P-FIX | 洁具 |
| A-DOOR / A-WIND | 门 / 窗 | A-DIM / A-TEXT | 标注 / 文字 |
| A-FURN / A-FURN-N | 家具 / 定制家具 | A-HATCH / A-FRAME | 填充 / 图框 |
| F-FIN / F-TEXT | 铺装分格 / 铺装标注 | A-NOTE | 注释引线 |

配套四档线宽（0.50/0.35/0.18/0.09）、拆除虚线 + 新墙实线的区分规则、五类常用比例（平面 1:50、立面 1:30、节点 1:10~1:2、总图 1:100）、A3/A2 图幅装订边与右下标题栏、字高按出图比例反算、模型空间 1:1 实尺 + 比例只在布局视口体现等硬规则。

## 适用场景

- 有户型尺寸数据，要直接生成可编辑的 DWG 平面图交给施工方
- 手上有几十张 DWG 要统一改图层名、批量检查实体与块参照
- 要按国标规范出 A3 施工图：图框、标题栏、图层、线型、比例一次到位
- 甲方给了原图，需要在副本上改方案并保留修改痕迹
- 想让 AI 接入 AutoCAD 做自动化出图，而不是每次手敲命令
- DXF 文件需要无头批量审查（本机没装 AutoCAD 也能跑）

## 使用技巧

1. 报清三件事再让它画：单位（默认 mm）、图纸标准（是否按 JGJ/T 244 图层表）、输出绝对路径。
2. 第一次用先跑 `python scripts\acad_preflight.py` 自检；缺 pywin32 会提示安装命令。
3. 想要“看着它画”就别加 `--fast`；批量任务才加 `--fast` 提速。
4. 本机没装 AutoCAD 时，走 `acad_headless.py` 做 DXF 只读检查 + 出图，一样能交付。
5. 改甲方原图前它默认另存副本并加 `_bak` 后缀，需要覆盖原图要显式授权。
6. 画完让它跑一遍 `acad_review.py` + `acad_preview.py`，实体数与预览图都过才算完成。
