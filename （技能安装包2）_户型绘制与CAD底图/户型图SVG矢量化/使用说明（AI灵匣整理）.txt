# 户型图SVG矢量化
**一句话定位：**户型 PNG → 只留墙/柱/门弧的干净矢量 SVG（自动阈值 + 可视化删减）。

户型图矢量化清洗工具：输入彩色 PNG 户型图，用 potrace 做矢量追踪，再通过**看图删路径**的方式把多余内容（文字、家具图标、指北针、尺寸线）滤掉，输出只剩结构要素的干净 SVG——为后续户型元素分类与 3D 建模做准备。

**为什么这样设计：** 户型图 PNG 里充满文字、家具图标、方位符号，直接矢量化会让后续识别无所适从。先追踪、再人工看图判断删留，才能得到干净的底图。

**环境要求：** 需要 ImageMagick（magick）与 potrace 两个命令行工具。

## 处理流程

**Step 1 · 检查输入图**：先读图确认三件事——墙线粗细与对比度、背景色（白/彩/灰）、文字与家具图标的多少。

**Step 2 · 动态阈值选择**：不做固定阈值，而是用 50%/60%/70%/80% 四档同时追踪出 4 张预览图，按四条标准挑最优：
- 墙线再现性：内外墙轮廓连续不断
- 噪点量：背景斑点越少越好
- 文字残留：残留可接受（后续会删），但要避免与墙线融成一团无法分离
- 门弧再现：门的扇形开启弧要能辨认

**经验对照表：** 粗线高对比白底 → 选 50-60%；细线/带灰调 → 70-80%；彩色分区背景 → 60-70%；背景噪点多 → 40-50%。拿不准就把 4 张预览给用户选。选完删除其它阈值文件。

━━━━━━━━━━━━━━━━━━━━ 淘宝店AI灵匣 ━━━━━━━━━━━━━━━━━━━━

**Step 3 · 路径编号 + 预览**：给 SVG 每条路径编号（path_001…），生成路径清单（含包围盒）与带编号的标注预览图，让你能看到每条路径对应画面里哪个元素。

**Step 4 · 删留判断**（按视觉特征分类）：

| 特征 | 处理 | 例子 |
|------|------|------|
| 汉字/字母/数字形状 | 删除 | 房间名、尺寸标注「LDK」「6帖」 |
| 箭头/指北针/方位符号 | 删除 | N 箭头 |
| 家具/设备形状 | 删除 | 浴缸、马桶、厨柜、沙发图标 |
| 尺寸线/引出线 | 删除 | 带箭头的直线 |
| 粗直线/矩形结构 | 保留 | 墙线 |
| 小方块结构 | 保留 | 柱 |
| 门的扇形弧 | 保留 | 开门轨迹（后续元素分类要用） |
| 分隔房间的线 | 保留 | 隔墙 |

**注意：** potrace 可能把相互接触的墙与非墙元素合并成同一条路径——碰到大包围盒的路径先怀疑它含墙，别急着删。删除多时用「仅保留」模式（keep），删除少时用「删除」模式（remove）。

**Step 5 · 迭代修正**：预览后若还有残留，重复「找出残留路径 id → 删除/保留 → 看新预览」直到干净。
