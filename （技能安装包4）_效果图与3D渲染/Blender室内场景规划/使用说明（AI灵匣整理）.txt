# Blender室内场景规划
**一句话定位：**渲染前先出「结构化场景计划书」：房间、材质、灯光、相机一次钉死再开工。

**触发场景：** 室内空间/客厅场景/办公室展示/酒店大堂/厨房展厅。

## 输入与输出

**必填输入：** 房间类型（驱动布局与家具）· 风格时代/美学（驱动材质与家具选型）· 一天中的时段（驱动自然光方向与强度）· 宽高比（构图规则）。
**选填：** 参考图/情绪板（风格校准）· 品牌指南（颜色+材质+品牌）· 指定家具品牌（资产采买）。
**待确认假设：** 房间可在合理预算内实现（资产/面数）· 建筑+家具+道具风格一致 · 相机锁定。

**输出（结构化场景计划）：**
```
房间：类型/尺寸/风格时代
建筑：墙/地/天花/窗/门
家具+道具：清单
材质：主调色板（3-5 个主导）+ 关键表面（地/墙/台/织物）
灯光：自然（窗+太阳方向+强度）| 人工（灯具+实际光源）| HDRI
相机：焦段 | 位置 | 视线高度 | 目标
情绪+时段：一句话
待发现资产清单 / 局限 / 下一步
```

## 九步操作程序 & 判定标准

**九步：** 读简报钉房间类型+风格 → 钉建筑基础 → 规划家具布局与道具 → 钉材质调色板 → 规划灯光（自然：窗+太阳；人工：灯具+实际光源）→ 钉相机角度+焦段 → 钉情绪+时段 → 列资产清单交发现环节 → 输出移交清单。

**Pass / Warn / Fail 判定：**
- **Pass**：各节齐全 + 风格一致合理 + 有灯光计划 + 资产已标记
- **Warn**：某一节含糊（调色板不清、时段与灯光不匹配）
- **Fail**：风格与家具冲突；相机不现实（4m² 房间用 14mm）；没有灯光计划

**决策树预警：** 100m² 家庭办公室 → 不现实，警告并核实意图；现代简报配繁复维多利亚沙发 → 冲突，二选一；正午却只计划人工光 → 警告，窗光应主导；小房间 14mm 广角 → 警告畸变，建议 24mm+ 相机后移。

## 三个实战 Playbook & 最佳实践

- **Playbook A 现代客厅主镜（16:9 目录图）**：24-35mm 广角、相机在角落、午后自然光穿窗、沙发+茶几+地毯为主家具、极简调色板、柔和阴影
- **Playbook B 酒店大堂（1:1 社媒）**：35mm、相机居中朝向焦点艺术/前台、暖人工光+少量自然光、材质丰富
- **Playbook C 办公室展厅（2.39:1 宽幅）**：24mm、相机抬高、自然+人工混合、干净材质、纵深分层（前景家具+中景工位+背景视野）

**最佳实践：** 自然+人工光一起规划（它们是一个系统）· 房间场景相机放角落而非正中（正中丢纵深）· 调色板早锁定（3-5 色封顶）· 窗户是光源不是装饰。

## 使用技巧

1. 相机一律放角落并明确焦段——正中机位是房间图发空的头号原因
2. 先锁 3-5 色调色板再谈材质，色彩打架全在后期救不回来
3. 把窗户当光源规划，自然光与人工光是同一套系统
