# AI空间改造可视化

AI 空间改造可视化——用 each::sense 图像智能体改造并可视化室内空间：**上传现有房间的照片，即可生成不同风格、家具、颜色与布局的重设计版本**。

**八项核心能力：**
- **整屋改造**：保留结构前提下把现有房间改成全新设计
- **风格转换**：现代/极简/波西米亚/工业等风格互转
- **家具试摆**：预览新家具放进你家的实际效果
- **配色预览**：墙面/点缀/装饰换色所见即所得
- **厨房改造**：橱柜/台面/电器更新可视化
- **浴室翻新**：瓷砖/台盆/五金更换预览
- **办公设计**：为效率与美感改造工作空间
- **前后对比**：并排生成改造前后对照图

## 快速上手（API 调用模板）

技能内置标准调用方式（需 eachlabs 的 API Key，配置在环境变量 `EACHLABS_API_KEY`）：

```
POST https://eachsense-agent.core.eachlabs.run/v1/chat/completions
Header: X-API-Key / Accept: text/event-stream
Body: {
  messages: [{role:user, content:"把客厅改成现代极简风：中性色、利落线条"}],
  model: eachsense/beta, stream: true,
  image_urls: ["https://.../我的客厅.jpg"], mode: max
}
```

**玩法示例：** ① 房间照片整体重设计（同布局换全部家具/装饰/配色，加一句「要更奢华当代、加特色主灯和绿植」）→ ② 风格转换（把杂乱传统客厅转成日式禅意极简：去多余家具、白+浅木、低矮沙发、枯山水元素）→ ③ 家具摆放可视化（给空房间加家具，看布局效果）。

## 多轮迭代精修

带 `session_id` 连续调用即可在同一项目上多轮细化：先发初版 →「床头板加大、多些暖木色、加点植物」→「床头加幅画、靠枕换灰粉色」，每次都在上一版基础上改，直到满意。

## 错误处理对照表 & 相关技能

| 报错 | 原因 | 解决办法 |
|---|---|---|
| Failed to create prediction: HTTP 422 | 余额不足 | 到 eachlabs.ai 充值 |
| Content policy violation | 内容违规 | 调整提示词符合内容政策 |
| Timeout | 生成复杂 | 客户端超时至少设 10 分钟 |
| Image not accessible | 图片 URL 无效/私密 | 改用可公开访问的图片 URL |

## 使用技巧

1. 照片用公共 URL 且光线清楚，改造效果最稳
2. 同一项目固定一个 session_id 反复追加修改，比每次重开更连贯
3. 先整体重设计一版，再局部微调两三轮即可定稿

【安装方式】
（三步安装 · 复制文件夹即用）
  只需三步，即可把本技能装进AI对话框直接使用：

  第1步｜复制技能文件夹：找到本技能所在的文件夹，
       右键 → 复制路径（或直接复制整个文件夹）。

  第2步｜放入智能体对话框：把复制好的文件夹路径粘贴到对话框里

  第3步｜输入安装指令，把下面这句话粘贴发送：

  【请解压这个技能包「AI空间改造可视化」，并安装到技能目录，
  完成后告诉我，后续对话我会直接使用它。】

  · 等AI回复"安装完成"即可正常使用。
  · 多个技能一起安装：把多个文件夹路径/文件夹一起放入对话框，
    再发送："请把上面这些技能包全部解压安装"。
  · 安装后直接描述需求，AI会自动调用本技能。
